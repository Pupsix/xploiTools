# XploiTools

A collection of simple security tools built for personal use and real-world bug hunting.

These tools were developed to help with vulnerability research, testing, and exploitation. Some of them have been used successfully during real-world security research to identify and exploit vulnerabilities.

## Purpose

This repository contains tools that I personally built, tested, and used during security research.

The goal is not to create full-featured scanners, but to build small and practical tools that solve specific problems encountered while hunting vulnerabilities.

## Disclaimer

These tools are provided for educational and authorized security testing purposes only.

Only use them against systems you own or have explicit permission to test.

Target-specific information, credentials, session data, and other sensitive information have been removed from public PoCs.
